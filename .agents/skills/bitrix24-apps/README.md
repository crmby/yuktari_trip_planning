# Скилл bitrix24-apps

Скилл для ИИ-агента (Claude Code, Codex): как делать приложения для Битрикс24 —
стиль интерфейса, подключение к данным портала, ключи, встраивание в Битрикс24
и выкладка на платформе VibeCode (vibecode.bitrix24.tech) или на своём сервере.

Источник: KiselevLab, курс «Вайбкодинг в Битрикс24». Собрано по открытой
документации Битрикс24, b24ui и VibeCode на 18.11.2026.

## Что внутри

```
bitrix24-apps/
├── SKILL.md                     порядок работы агента и правила (читает агент)
├── README.md                    этот файл (для человека)
├── references/
│   ├── bitrix24-style.md        стиль приложений Битрикс24 (Air, b24ui, токены)
│   └── bitrix24-apps.md         приложения, ключи, API, встраивание, деплой
└── assets/
    └── b24-tokens.css           готовые стили для HTML/PHP-страниц
```

Справочники из `references/` можно отдавать агенту и без скилла — как обычные
MD-файлы: положить в проект и попросить прочитать.

## Установка

### Claude Code

Для всех проектов — распаковать архив в `~/.claude/skills/`,
для одного проекта — в `.claude/skills/` внутри проекта.

```bash
mkdir -p ~/.claude/skills
unzip -o bitrix24-apps-skill.zip -d ~/.claude/skills/
# должно получиться ~/.claude/skills/bitrix24-apps/SKILL.md
```

Перезапустите Claude Code. Проверка: спросите агента «какие скиллы у тебя есть?»
— в списке должен быть `bitrix24-apps`.

### Codex

Для всех проектов — `~/.agents/skills/`, для одного проекта — `.agents/skills/`
внутри проекта.

```bash
mkdir -p ~/.agents/skills
unzip -o bitrix24-apps-skill.zip -d ~/.agents/skills/
# должно получиться ~/.agents/skills/bitrix24-apps/SKILL.md
```

Если скилл не появился — перезапустите Codex.

### Windows

Распакуйте архив проводником в `C:\Users\<имя>\.claude\skills\` (Claude Code)
или `C:\Users\<имя>\.agents\skills\` (Codex).

## Как пользоваться

Просто ставьте задачу про Битрикс24 — агент подключит скилл сам. Примеры:

- «Сделай дашборд по сделкам моего Битрикс24 и встрой его в портал.»
- «Приведи интерфейс этого проекта к стилю Битрикс24.»
- «Выложи приложение на VibeCode» или «…на мой сервер».

Можно позвать явно: «Используй скилл bitrix24-apps».

## Безопасность

В скилле нет ключей и данных порталов. Свои ключи (vibe_api_…, client_secret,
ссылку вебхука) не вставляйте в код страницы, в Git и в общие чаты — только в
настройки сервера (переменные окружения, секреты приложения).
