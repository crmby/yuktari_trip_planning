# Планирование выездов

Общение и документация — на русском. Перед работой прочитать README.md и docs/PROJECT.md.
Для работы с Битрикс24 использовать .agents/skills/bitrix24-apps/SKILL.md.

- Рабочее приложение: src/ и public/. PHP-комплект в templates/b24-advanced-php/ — справочный исходник; его инструкции относятся к этому каталогу.
- Секреты, .env и данные портала не читать, не выводить и не коммитить. Использовать .env.example с пустыми значениями.
- Не считать заголовки X-Vibe-* или параметры URL доказательством входа без проверки доверенной среды и сессии. Не добавлять CRM API до реализации авторизации.
- Пользователь разрешил инициализацию Git и настройку окружения. Создание платных ресурсов и реальная выкладка в текущий этап не входят.
- Перед коммитом просмотреть diff и добавлять файлы поимённо. Не переписывать существующую удалённую историю.
- Проверки: npm run check, npm test, npm run deploy:check. После изменений обновлять memory/state.md.
- Postman CLI установлен и может использоваться для работы с API.
