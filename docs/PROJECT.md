# Карточка проекта

- Название: «Планирование выездов».
- Проект: Юктари / crmby.
- Среда размещения: Bitrix24 VibeCode, согласно запросу пользователя.
- Репозиторий: https://github.com/crmby/yuktari_trip_planning.
- Первый этап: структура проекта, Git, локальное окружение, подготовленная команда деплоя.
- Реализовано: Node.js-сервер без сторонних зависимостей, стартовый экран со стилями Air, health, проверки, упаковка, подготовленный деплой по образцу SyncPoint.
- Не реализовано: хранение выездов, календарь, CRM-запросы, роли, проверка сессии сотрудника и установка внутри портала.
- Не определены: домен портала, ID существующего сервера, модель данных выезда, роли и места встраивания.
- Секреты: только локальные переменные среды / `.env`, не в Git и не в чате.
- Изменения данных CRM, создание сервера и реальная выкладка в текущем этапе не выполняются.

## Источники

`b24-advanced-php.zip` сохранён в `templates/b24-advanced-php/`; `bitrix24-apps-skill.zip` установлен в `.agents/skills/bitrix24-apps/`. Указания исходного PHP-комплекта относятся к справочному каталогу и не подменяют запрос пользователя.

`../SyncPoint/deploy.ps1` использован как образец multipart-доставки в VibeCode. Чужие `.env`, ключи, ID сервера и данные не переносились.
