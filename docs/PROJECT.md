# Карточка проекта

- Приложение «Планирование выездов», Юктари / crmby, Node.js без сторонних зависимостей.
- Репозиторий: https://github.com/crmby/yuktari_trip_planning, основная ветка main.
- Портал: yuktari.bitrix24.by.
- Существующий сервер: d4cd0430-b066-441c-bfc7-62107a20b977.
- APP_URL: https://app-13fb2e983443.vibecode.bitrix24.tech.
- Этап: версия 0.3 для ручного деплоя пользователем, с реализацией CRM-синхронизации и вкладки сделки.
- Реализованы авторизация по проверенной сессии VibeCode, поиск и контекст сделки, карта девяти UF-полей, маршруты из инфоблока, все товарные позиции, общий резерв, серверное хранение, мастера из сотрудников, группы, направления, графики, проверка результата CRM и команда привязки CRM_DEAL_DETAIL_TAB.
- Демо остаётся отдельным режимом с вымышленными данными в браузере. В рабочем режиме демо-данные не используются и не подставляются при ошибке доступа.
- Wialon: интеграция исключена пользователем; хранится только необязательный идентификатор мастера. Стадии и товары сделки не меняются.
- Секреты: только .env/защищённая среда, не в Git, браузере и чате. Пользователь подтвердил наличие OAuth-приложения и добавит VIBE_APP_KEY самостоятельно.
- Поля и данные: docs/FIELD-MAP.md; настройка, ограничения и приёмка: docs/CRM.md; ручная доставка: docs/MANUAL-DEPLOY.md.
- Проверено локально с вымышленным API. Реальная сессия, типы полей портала, доступы инфоблока, выкладка и привязка вкладки пока не проверены и агентом не выполнялись.

## Источники

b24-advanced-php.zip сохранён в templates/b24-advanced-php/; bitrix24-apps-skill.zip установлен в .agents/skills/bitrix24-apps/. Инструкции PHP-комплекта относятся только к его справочному каталогу. ../SyncPoint использован как образец доставки; чужие ключи и данные не переносились.

- Версия 0.3.5: единый поиск сделки/сотрудника, длительность числом, адрес через карточку контакта, автоматическая проверка сохранения текущей сделки, живой календарь и все направления по умолчанию. Справочники обновляются отдельно кнопкой.

- Версия 0.3.6: единый JSON-фильтр календаря, активность поиска по stageSemanticId=P, безопасная диагностика отклонённого поля; при UNKNOWN_FILTER_FIELD сохранённые выезды перечитываются по ID и остаются видны с явным предупреждением о неполном списке CRM.
