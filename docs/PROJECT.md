# Карточка проекта

- Название: «Планирование выездов».
- Проект: Юктари / crmby.
- Среда размещения: Bitrix24 VibeCode, согласно запросу пользователя.
- Репозиторий: https://github.com/crmby/yuktari_trip_planning.
- Текущий этап: тестовая версия по ТЗ, которую пользователь задеплоит вручную.
- Реализовано: Node.js-сервер без сторонних зависимостей, четыре рабочих экрана Air, получасовой маршрутный лист, создание/перенос/отмена тестовых выездов, мастера и группы, недельные графики, календарь месяца и исключения, расчёт доступности и конфликтов, локальное хранение и проверки.
- Не реализовано: общий серверный резерв для нескольких сотрудников, CRM-запросы и синхронизация, серверная авторизация, регистрация вкладки сделки и приёмка в портале. Карта полей подготовлена без выдуманных CRM-кодов.
- Wialon: исключён из текущей работы по явному указанию пользователя; вызовы, обработчики и изменения существующей интеграции не выполняются.
- Портал: `yuktari.bitrix24.by` (указан пользователем).
- Существующий сервер VibeCode: `d4cd0430-b066-441c-bfc7-62107a20b977` (из переданного пользователем пути API).
- Адрес приложения: https://app-13fb2e983443.vibecode.bitrix24.tech (указан пользователем; работа приложения по этому адресу не проверена).
- Планируемое место встраивания: вкладка сделки `CRM_DEAL_DETAIL_TAB`; до подключения данных требуется настройка OAuth-приложения и проверка сессии.
- Модель данных и тестовое правило резервирования описаны в docs/DEMO.md; боевые правила и CRM-поля требуют согласования.
- Секреты: только локальные переменные среды / `.env`, не в Git и не в чате.
- Изменения данных CRM, создание сервера и реальная выкладка в текущем этапе не выполняются.
