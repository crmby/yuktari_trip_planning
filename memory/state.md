# Состояние на 26.11.2026

## Текущий этап: тестовая версия 0.2

По запросу пользователя подготовлено демо по предоставленному ТЗ для последующего ручного деплоя. Работают четыре экрана: маршрутный лист, запись из сделки, мастера/группы, графики. Добавлены создание/перенос/отмена/восстановление выездов, все товары тестовой сделки, фильтры, территории и координаты, отдельные позиция/окно/длительность, автоматическое назначение по группам и сменам, календарь месяца и конфликты. Демо хранится только в браузере; Wialon исключён пользователем и не затрагивается.

Проверено: 11 тестов Node.js и проверка синтаксиса; в браузере — создание/перенос/отмена, сохранение после перезагрузки, обычная неделя и исключения, конфликты, группы и новые мастера, фильтр города, ссылка на карту и контекст тестовой сделки. Ошибок в консоли браузера при проверке не обнаружено. Архив создаётся офлайн, без .env и справочного PHP-комплекта. Обёртки deploy.ps1 и deploy.sh добавлены для ручного запуска.

Реальные CRM-записи, авторизация сотрудника, атомарное серверное резервирование, общая база для нескольких менеджеров, геокодер и регистрация CRM_DEAL_DETAIL_TAB остаются отдельным этапом. Это не полная приёмка рабочего приложения по всем пунктам ТЗ. Ограничения и сценарии описаны в docs/DEMO.md; предварительная карта полей — docs/FIELD-MAP.md; ручная доставка — docs/MANUAL-DEPLOY.md.
