# Операционные ограничения

- Это публикационный исходный комплект, не настроенная рабочая среда и не результат live-приёмки.
- Корень, владелец, домен, портал, роли, credentials, storage, версия runtime и контур задаются для нового проекта явно.
- Не переносить чужие значения, серверные пути, аккаунты и настройки доступа. Нет зависимости от личных каталогов правил.
- Рабочие секреты и данные запрещены в Git и документации; локальные runtime-конфиги не входят в комплект.
- Общая безопасная команда: `python3 tools/portable-lint.py` из корня этого комплекта.
  Она запускает только PHP lint, node --check, разбор JSON и Python compile без исполнения приложений.
  При отсутствии инструмента проверка завершается ошибкой, а не ложным PASS.
- Корпоративные deploy/snapshot/credentials scripts и agent settings удалены. Вместо них — [ручная настройка](SETUP.md).
  Комплект не выполняет автоматические commits, публикацию, установку cron, выдачу доступа или запись во внешние правила.
- Для выпуска отдельно проверить auth/ACL, установку/переустановку, refresh/session renew, роли, storage isolation,
  uninstall, восстановление и резервную копию. Мутации CRM — только на отдельном тестовом портале с разрешением.
- После работы обновлять memory/state.md, memory/decisions.md, memory/log.md: факты отдельно от планов.
