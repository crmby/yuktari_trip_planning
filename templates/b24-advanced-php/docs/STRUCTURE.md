# Структура

INDEX.md — навигация; AGENTS.md — общий порядок; CLAUDE.md — тот же вход.
docs/PROJECT, OPERATIONS, SETUP — назначение, ограничения и ручная настройка.
memory/state, decisions, log — состояние, основания решений и проверенные действия.
docs/technical — адаптированная исходная архитектура и технические правила.
src/ — Node-код универсального комплекта; www/ — PHP webroot остальных.
tests/ и tools/ — исходные проверки/утилиты там, где есть; portable-lint — только синтаксис.
